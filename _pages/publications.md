## Undergraduate Thesis

### Sentiment Analysis from a Bengali Dataset Using Hybrid Deep Learning and Contextualized Word Embedding Techniques
*2024*

Utilized contextualized Bangla BERT word embedding techniques to replace traditional methods (Word2Vec, GloVe, FastText) combined with a CNN-BiLSTM model, achieving **96.84% accuracy**. Compared performance with 8 machine learning and 2 deep learning models, and introduced a feature for expressing sentiment with relative sentiment scores.
